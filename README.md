## Experiments with Python.
> Create the virtual environment:
 ```
 python3 -m venv .venv
 ```
> Ativate the virtual environment: 
  ```
  source ./.venv/bin/activate
  ```
> if you use fish:
  ```
  source ./.venv/bin/activate.fish
  ```
> run the script (example): 
  ```
  python3 convert-temp.py
  ```
